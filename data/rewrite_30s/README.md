# Rewrite 30s dataset (pilot)

Generated by `scripts/rewrite_data.py` with local `qwen2.5:14b` (Ollama), starting
from `data/clean`:

| split | source | accepted | rejected | target |
|---|---|---:|---:|---|
| train | clean/shampoo_train.json | **50** | 0 | 30s, 10-12 shots |
| val | clean/shampoo_val.json | **15** | 0 | 30s, 10-12 shots |

All accepted rows pass the mechanical gate:

- 10-12 shots, total duration exactly 30s
- five non-empty fields
- continuous time axis, no zero-duration shots
- voiceover <=4 chars/sec
- no invented known brands
- time axis deterministically re-timed after generation

Files:

- `train.json` / `val.json` — SFT-ready rows with `target_duration_sec` / `target_shots`
- `*_accepted.jsonl` / `*_rejected.jsonl` — audit trail (attempts, model, errors)
- `*_quality.json` — accept/reject counts
- `*_review.csv` — **human spot-check sheet** with flags
- `*_README.md` — per-split detail

**Status: draft, needs human review.** The mechanical gate is not a creative
quality gate. Current known weaknesses:

- 33/50 train rows are flagged `generic_cta` (e.g. "限时优惠，速来抢购")
- 23/50 train rows have at least one `short_visual`
- some rows repeat a voiceover line within the script

Review workflow:

1. Open `train_review.csv` / `val_review.csv`; the `flags` column highlights
   generic CTA, duplicate voiceover, low type diversity and short visuals.
2. Reject rows with wrong claims, unusable visuals, or copy that is too generic.
3. Regenerate rejected rows with a tighter brief or fix by hand; then rerun
   `python scripts/summarize_rewrite.py --dir data/rewrite_30s --split train`.
4. Only after review should this become the SFT/DPO training set.

This pilot is intentionally small. To expand after review:

```bash
python scripts/rewrite_data.py --limit 200 --resume --out-dir data/rewrite_30s
python scripts/summarize_rewrite.py --dir data/rewrite_30s --split train
```
