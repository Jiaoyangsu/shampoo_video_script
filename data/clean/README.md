# Cleaned data

Generated by:

```bash
python scripts/clean_data.py
```

- `shampoo_train.json` — 528 SFT rows, mechanically clean
- `shampoo_val.json` — 59 held-out SFT rows
- `dpo_train.json` — 528 DPO pairs built from SFT train
- `dpo_val.json` — 59 DPO pairs built from SFT val
- `quality_report.json` / `QUALITY_REPORT.md` — gate config, rejection counts, hashes
- `SHA256SUMS` — checksums for the JSON files

The gate removes empty voiceover/music, zero-duration shots, broken/overlapping
time axes and duplicate outputs.  It does **not** claim the scripts are creative
or that the pacing is good; 82.2% of the remaining shots still exceed 4 chars/sec
at the original time axis.  See `evaluation/REPORT.md`.
